# Getting help with simple-icons-swift

Help is best effort; the documentation answers most questions fastest.

## Read first

- [README](README.md): installation, usage and the legal disclaimer.
- [Documentation](https://swiftpackageindex.com/Vernum-Projecten/simple-icons-swift/documentation):
  every public type and function.
- [Simple Icons](https://simpleicons.org): find an icon and its slug.

## Ask or report

- **A new icon, or a wrong one:** at [Simple Icons](https://github.com/simple-icons/simple-icons/issues/new/choose).
  This package takes the icons unchanged and picks up the fix with the next release.
- **A bug in the package:** open a [bug report](https://github.com/Vernum-Projecten/simple-icons-swift/issues/new?template=bug_report.yml).
- **An idea:** open a [feature request](https://github.com/Vernum-Projecten/simple-icons-swift/issues/new?template=feature_request.yml).
- **A vulnerability:** privately, as [SECURITY.md](SECURITY.md) describes;
  never in an issue.

Search the [open and closed issues](https://github.com/Vernum-Projecten/simple-icons-swift/issues?q=is%3Aissue)
first; your question may already have an answer.

## What a bug report needs

- the package version, the Xcode or Swift version, and the platform;
- the smallest code that shows the problem, what you expected and what
  happened;
- for a drawing problem, the icon's slug and a screenshot.
